# Stat 159 Project 2
[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/UCB-stat-159-f25/proj02-group27.git/HEAD)
This project focuses mainly on natural language processing of State of the Union speeches from every United States President. It follows a rational pathway from exploratory data analysis. From there, it uses language analysis tools like lemmatization and vectorization to process more in-depth and targeted forms of analysis.
